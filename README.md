# KLUTCH 11 — BRIGHTSIDE

Analogue-inspired vocal warmth and harmonic enhancement for Windows VST3 hosts.

## Controls
Drive, Tube, Tape, Body, Presence, Air, Tone, Density, Mix, Input, Output and Quality (2x / 4x / 8x).

## Build
GitHub Actions builds the Windows x64 VST3. Download the `KLUTCH-11-BRIGHTSIDE-VST3` artifact from Actions and copy the complete `.vst3` bundle into:
`C:\\Program Files\\Common Files\\VST3`

BRIGHTSIDE uses custom digital saturation curves inspired by tube and tape behaviour; it is not a circuit-level analogue emulation.
